# A3/A4 Page Count Tool
This tool counts pages of A3 and A4 size in batches of scanned documents.
Statistical results can be exported to Excel for archive digitization inspection.

## ✨ Features
- Batch recognition and counting of A3 / A4 pages
- Summary statistics for document batches
- Export all counting data to Excel (.xlsx)
- Lightweight, easy deployment for archive digitization workflows

## 📌 Use Cases
Archive digitization, batch document quality inspection, paper volume statistics.

## 🚀 Quick Start
1. Prepare scanned document files.
2. Run the program and import target files.
3. Start page recognition and counting.
4. Export statistics report to Excel.

## 🧰 Requirements
- windows10/11
